# 다음 작업 목록

이 문서는 현재 구현 이후에 남은 작업을 우선순위로 정리한다. 이미 구현된 기능을 다시 결정해야 하는 항목은 두지 않고, 운영 품질을 높이거나 공개/개인 경계를 더 명확히 하는 작업만 남긴다.

## 반복 운영 항목

- 공개 snapshot을 새로 발행할 때마다 `python scripts/publication_gate.py`를 실제 운영 문자열 custom term과 함께 실행한다.

## 우선순위 낮음

- 공개용 architecture diagram 확장
- 반복 일정, 카테고리별 기본 알림 시간, 커스텀 snooze 확장 검토

## 완료된 운영 정리 항목

- 공개 demo seed는 `llm-wiki demo-seed` 명령으로 제공한다. 합성 원문, 소스, 승인/미검토/거절 제안, 주제/대상, 일정 항목을 만들며 같은 기준일로 재실행해도 중복 생성하지 않는다.
- 저장된 대화 세션은 웹 삭제 시 soft delete로 숨기고, 운영자는 `llm-wiki chat-cleanup --deleted-retention-days N`으로 삭제된 세션과 turn을 hard purge한다. 대화 이력은 App DB 백업에 포함되며, purge 전 백업에는 남을 수 있음을 문서화했다.
- 웹 제안 목록에서 여러 미검토 제안을 선택해 일괄 승인/거절할 수 있고, 거절됨 필터에서는 여러 항목을 일괄 복원할 수 있다.
- 모바일 일정/알림 상세 화면에 `목록으로` 버튼을 추가하고 모바일 탭과 목록 선택 상태를 접근성 속성으로 갱신한다.
- 운영 대시보드의 실패 그룹은 실제 요청에 저장된 runner, 입력 방식, 출처, 정규화된 실패 원인별로 묶어 표시한다.
