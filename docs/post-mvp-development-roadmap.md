# 후속 개발 로드맵

MVP 이후에는 개인용 메모 서비스를 범용 지식 워크벤치로 확장한다.

## 제품 확장

- 다중 사용자와 workspace 분리
- 공유 가능한 읽기 전용 노트 링크
- 긴 문서 import와 chunk 기반 분석
- 반복 일정과 습관형 알림
- 외부 캘린더 export

## AI 확장

- 모델별 runner 선택
- 비용 한도와 월별 사용량 추적
- 답변 품질 평가 fixture
- 장기 메모 요약과 자동 정리 제안

## 운영 확장

- 배포 자동화
- 백업 restore drill 자동화
- secret rotation 절차
- 장애 알림과 상태 페이지

## 데이터 확장

- Markdown mirror 외부 소비 API
- 첨부파일 중복 제거
- 검색 인덱스 또는 vector index 검토
