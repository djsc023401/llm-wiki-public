# 주제, 대상, 태그, 일정 제안 형식

AI runner는 source note 안에 검토 가능한 제안을 남긴다. 사람이 승인하기 전에는 주제/대상/태그/일정으로 확정하지 않는다.

## 주제 제안

```markdown
| 후보 | 제안 경로 | 근거 | 검토 메모 |
| --- | --- | --- | --- |
| 배당률 | wiki/topics/dividend-yield.md | "연 배당률" | 투자 지표 주제로 검토 |
```

## 대상 제안

```markdown
| 후보 | 유형 | 제안 경로 | 근거 | 검토 메모 |
| --- | --- | --- | --- | --- |
| QQQI | ETF | wiki/entities/qqqi.md | "QQQI" | 티커 여부 확인 |
```

## 태그 제안

```markdown
| 후보 | 근거 | 검토 메모 |
| --- | --- | --- |
| 생활용품 | "치약" | 소비재 메모로 분류 가능 |
```

## 일정 제안

```markdown
| 후보 | 의도 | 유형 | 시작 | 종료 | 마감 | 알림 | 시간대 | 근거 | 검토 메모 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 병원 예약 | 일정 | event | 2026-07-01T10:00:00+09:00 |  |  | 2026-07-01T09:00:00+09:00 | Asia/Seoul | "7월 1일 병원" | 날짜 확정 필요 |
| 예약 완료 기록 | 기록 전용 | reminder |  |  |  |  | Asia/Seoul | "예약 완료" | 완료 사실만 기록하고 일정/알림으로 등록하지 않음 |
```

## 원칙

- 상대 날짜는 기준 시각과 함께 절대 날짜 후보를 기록한다.
- 일정 제안의 `의도`는 `기록 전용`, `일정`, `할 일`, `마감`, `후속 확인`, `알림` 중 하나로 기록한다.
- `기록 전용`은 과거 사실이나 완료 상태를 보존하기 위한 후보이며 실제 일정/알림으로 등록하지 않는다.
- 근거는 원문에서 확인 가능한 짧은 문구를 사용한다.
- 불확실한 정보는 검토 메모에 남긴다.
- 사람이 승인한 항목만 DB 연결 또는 일정으로 반영한다.
